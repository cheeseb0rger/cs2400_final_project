# cs2410_final_project

### Goal:  to find the relationships between popualtion growth, age distribution, and economic factors over time. 

### Dataset: 
https://databank.worldbank.org/source/world-development-indicators 

### Time frame:  
1961 - 2023

### Currently used countries / aggregates: 
- world (aggregate) 
- low_income countries (aggregate)
- middle_income countries (aggregate)
- high_incom countries (aggregate)
- united_states
- japan
- china
- india 

### Avalible plots: 
- age demographics over time 
- population growth and labor force rates over time 
- dependency ratios over time 
- dependency ratios vs economic factors. Factors:
	- GDP 
	- imports (total, %, net)
	- exports (total, %, net)
	- gross domestic savings (savings rates as % GDP)
	- final consumption expenditure
